# Tarrs Desktop

Installers for the [Tarrs](https://tarrs.io) desktop app.

**Download the latest version from [Releases](https://github.com/TarrsAI/tarrs-desktop-releases/releases/latest):**

- **macOS** — `Tarrs-<version>-arm64.dmg` (Apple Silicon) / `Tarrs-<version>.dmg` (Intel)
- **Windows** — `Tarrs-Setup-<version>.exe`
- **Linux** — `Tarrs-<version>.AppImage` / `.deb`

The app updates itself automatically on Windows and Linux. This repository
hosts installers and the update feed only; it accepts no contributions.
